# Roam.AI

An AI travel companion that turns a location and an amount of free time into a concrete itinerary, combining an interactive Google Maps interface with Claude-generated recommendations and a community feed of places contributed by other travellers.

Built by a four-person NYU team over a two-day hackathon in March 2025.

## What It Does

Most travel apps either show you a map or give you a list. Roam.AI starts from a different question: you are somewhere, you have a few hours, what should you actually do?

The recommendation flow takes your current location, how much time you have, and what you are interested in, finds nearby places from the database, and sends that context to Claude to produce a time-aware itinerary rather than an unranked list of pins.

**Core features**

- **Interactive map** built on the Google Maps JavaScript API, with places rendered as markers you can explore directly
- **AI itineraries** generated by Claude 3.5 Sonnet, taking your location, available hours, and nearby places as context
- **Community content** where travellers post places and experiences, browsable by category
- **Proximity search** returning content and places near a given coordinate, with distance computed server side
- **Voting** on community submissions
- **Category filtering** across the content feed

## Architecture

A two-tier application: a Flask REST API backed by SQLite, and a React single-page client.

```
backend/
  run.py                      Entry point
  app.py                      Application setup
  config.py                   Environment-driven configuration
  init_db.py                  Database initialisation
  app/
    routes/                   HTTP layer
      recommendations.py      Claude itinerary generation
      places.py               Place lookup, filtering, proximity
      content.py              Community feed, voting
      auth.py
    services/
      claude_service.py       Anthropic API integration, distance maths
      recommendation.py       Recommendation assembly
    models/
      content.py              Community content model
    data/                     Seed and dummy content

frontend2/
  src/
    App.js                    Application shell and state
    components/
      Map.js                  Google Maps integration
      ContentView.js          Community content browsing
      AboutUs.js              Team page
      SearchBar.js  CategoryTabs.js  LocationList.js  Navigation.js
```

**The API** exposes 11 endpoints across three blueprints:

| Method | Endpoint | Purpose |
| --- | --- | --- |
| POST | `/api/recommendations` | Generate an AI itinerary |
| GET | `/api/places/all` | All places |
| GET | `/api/places/filtered` | Places by filter |
| GET | `/api/places/nearby` | Places near a coordinate |
| GET | `/api/content` | Community content feed |
| GET | `/api/content/<id>` | Single content item |
| GET | `/api/content/nearby` | Content near a coordinate |
| POST | `/api/content/<id>/vote` | Vote on content |

**The Claude integration** in `claude_service.py` calls the Anthropic Messages API directly with `claude-3-5-sonnet-20241022`, passing the user's request, available hours, nearby places, and location so the model can sequence suggestions against the time budget. The same module implements the haversine distance calculation used for proximity queries.

## Setup

Requires Python 3, Node.js, a Google Maps API key, and an Anthropic API key.

**1. Backend**

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install flask flask-sqlalchemy flask-cors python-dotenv requests
```

`requirements.txt` is present but empty, so install the dependencies directly as above.

Copy the environment template and fill in your own keys:

```bash
cp .env.example .env
```

```bash
FLASK_APP=app.py
FLASK_ENV=development
GOOGLE_MAPS_API_KEY=your-key
ANTHROPIC_API_KEY=your-key
```

Initialise the database and start the server:

```bash
python init_db.py
python run.py
```

**2. Frontend**

```bash
cd frontend2
npm install
npm start
```

The client opens at `http://localhost:3000`.
